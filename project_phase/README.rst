Bug Tracker
===========

Bugs are tracked on `GitHub Issues <https://github.com/Mint-System/Odoo-Apps-Project/issues>`_.
In case of trouble, please check there if your issue has already been reported.
If you spotted it first, help us to smash it by providing a detailed and welcomed
`feedback <https://github.com/Mint-System/Odoo-Apps-Project/issues/new?body=module:%20project_phase%0Aversion:%2016.0%0A%0A**Steps%20to%20reproduce**%0A-%20...%0A%0A**Current%20behavior**%0A%0A**Expected%20behavior**>`_.
